# Mithelfen

**FoE Helper** ist vollständig Open Source und auf GitHub verfügbar. Egal ob Entwickler, Übersetzer oder einfach jemand mit guten Ideen – es gibt viele Möglichkeiten, wie du zur Verbesserung der Erweiterung beitragen kannst.

## Arten der Mitwirkung

Wir freuen uns über jede Art von Unterstützung für FoE Helper, zum Beispiel:

- Übersetzungen der Erweiterungs-UI, der Website oder der Dokumentation  
- Entwicklung und technische Beiträge
- Fehler melden oder Ideen teilen

Jeder Beitrag hilft uns, das bestmögliche Tool für die Forge of Empires Community zu schaffen.

## Übersetzungen

Die Benutzeroberflächen des FoE Helper und der Website basieren auf Übersetzungsdateien, die über [Weblate](http://i18n.foe-helper.com/projects/foe-helper/) verwaltet werden.

Wenn du an der Dokumentation mithelfen möchtest, findest du eine Anleitung auf [GitHub](github.md).

Wir freuen uns über neue Übersetzungen oder Verbesserungen in jeder Sprache.

## Entwicklung

Entwickler sind jederzeit willkommen! Du kannst den Quellcode durchstöbern, Fehler beheben, neue Funktionen implementieren oder die Leistung verbessern.  
Besuche das [GitHub-Repository](https://github.com/mainIine/foe-helfer-extension), um loszulegen. Beiträge per Pull Request auf den **Beta-Branch** sind sehr willkommen.

{% hint style="danger" %}
Alle anderen Pull Requests werden sofort abgelehnt.
{% endhint %}

Wenn du dich über Entwicklungsideen austauschen, Fragen stellen oder Unterstützung erhalten möchtest, tritt gerne unserer Community auf [Discord](https://discord.gg/z97KZq4) bei.

## Fehler & Verbesserungsvorschläge

Einen Fehler entdeckt oder eine Idee, wie wir FoE Helper besser machen können? Deine Rückmeldung hilft uns, Probleme zu beheben und die Erweiterung für alle zu verbessern.

Besuche die [GitHub-Issue-Seite](https://github.com/mainIine/foe-helfer-extension/issues), um offene Themen zu durchsuchen oder selbst etwas zu melden.
