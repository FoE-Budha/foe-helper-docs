# Helping Out

**FoE Helper** is fully open-source and available on GitHub. Whether you're a developer, translator, or just someone with great ideas—there are many ways you can contribute to making the extension even better.

## Ways to Contribute

We welcome all types of contributions to FoE Helper, including:

- Translating the extension UI, website, or documentation
- Helping with development
- Reporting bugs or sharing ideas

Every contribution helps us build the best possible tool for the Forge of Empires community.

## Translations

The UI of both the FoE Helper extension and website is powered by translation files managed on [Weblate](http://i18n.foe-helper.com/projects/foe-helper/).

If you want to help with documentation, check out the [GitHub guide](github.md).

We welcome new translations or improvements in any language.

## Development

Developers are always welcome! You can explore the source code, fix issues, implement new features, or improve performance.  
Visit the [GitHub repository](https://github.com/mainIine/foe-helfer-extension) to get started. Contributions via pull requests to **Beta Branch** are highly appreciated.

{% hint style="danger" %}
All other pull requests are rejected immediately.
{% endhint %}

If you’d like to discuss development ideas, ask questions, or get help, feel free to join our community on [Discord](https://discord.gg/z97KZq4).

## Bugs & Feature Ideas

Found a bug or have an idea for improvement? Reporting issues helps us fix problems and make FoE Helper even more useful for everyone.

Visit the [GitHub Issues page](https://github.com/mainIine/foe-helfer-extension/issues) to browse open issues or submit your own.
