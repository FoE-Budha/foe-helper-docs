# Work with GitHub

You’re welcome to help expand the FoE Helper documentation!
Before submitting content, please review the following contribution rules and formatting guidelines.

## ✅ Contribution Guidelines

### Writing and Structure

- The documentation is written in [Markdown](markdown.md)
- See how to structure an individual documentation page here: [Documentation Guide](documentation.md)
- For translations, utilize the existing English version of the page as a base
- If you're creating a new page from scratch, use the official [template](/en/module/_template/README.md) to ensure consistent formatting

### Submitting Your Contribution

- If your language is missing, you can add it by following the existing structure
- All contributions must be submitted as a **pull request to the `beta` branch** of the repository: [foe-helper-docs on GitHub](https://github.com/mainIine/foe-helper-docs)
- Once your content is ready, open a pull request
- We will review your submission and provide feedback or approve it if everything is in order
- Please note: we reserve the right to edit, remove, or reject any submission

{% hint style="danger" %}
**Pull requests to any other branch are automatically rejected**
{% endhint %}

Thanks for helping make the documentation better for everyone!
